# Markdown
Markdown is a markup language that is used a LOT on GitHub and is supported natively in pretty much every input box on GitHub.
It allows you to do basic (and more advanced) formatting with very little effort.
And since it's just a text file, any operating system (apart from, of course, iOS) can natively open them.

The highlights:
-  Use `# TITLE` to create a heading
-  Use `## TITLE` to create a subheading
-  Use `### TITLE` to create a subsubheading, etc
-  Use `*text*` to create *italic text*
-  Use `**text**` to create **bold text**
-  Use `***text***` to create ***bold and italic text***
-  Use `- item` to create a list
-  Use `[Display content of link](https://janishutz.com)` to create a [link](https://janishutz.com)
-  Use `![Alt text](https://cdn.janishutz.com/logo.jpg)` to insert an image
-  Use two linebreaks to create a linebreak. You can use linebreaks in text that isn't supposed to have a linebreak as a result.

You can preview your changes by clicking the "preview" button on GitHub
