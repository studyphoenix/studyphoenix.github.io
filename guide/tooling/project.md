# GitHub Projects
We use this to track progress on issues that are scattered across multiple repos.
It also gives a nice overview of what remains to be done and has multiple pages that each have pre-applied filters,
that make looking at certain types of tasks much quicker.

You can also see progress of subissues here, filter by labels, see what needs to be discussed in the meeting
(if you have something that you need to look at in a meeting, then add the `meeting` label to it)

There is also a sidebar that you can open (top right corner), which contains information on each of the tabs.
