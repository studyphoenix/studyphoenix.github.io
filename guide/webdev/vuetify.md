# Vuetify
Vuetify is a framework that adds prebuilt components to Vue.js, meaning that you won't spend your time building components that have been built already by someone else.
The downside of course is that it's much less flexible in terms of design you can do, but for our purposes this is more than good enough.
[Vuetify Docs](https://vuetifyjs.com)

Make sure to have a look at the components and the rest you can figure out as you go.
The setup work has been done and I will be adding proper theme support at some point.
If you build as it is intended by Vuetify, everything should just work when the theme change is implemented
